## Awaiting owner

Each of these is a reading taken without the owner under guide rule 5. Each is written into the spec and logged in DECISIONS. Each item names the PR and entry that raised it.

1. **Example files.** Confirm `three_machine_line.json` and `warehouse.json`, or supply the originals: owner question 1, AKS-74, option (a) or (b). Raised by PR #13 and the AKS-93 entry.
2. **Quantity grammar.** It is exact: a JSON number, one space, then `s`, `min`, `h` or `d` written exactly. For example, `2 ms` and `2 minutes` are rejected. Raised by PR #3 and the AKS-85 entry.
3. **Units layer readings.** Raised by PR #4 and the AKS-86 entry.
   - A unit name with several readings is E140 only when no reading is a time. For example, `2 cd` is E141, since centi-day is a time.
   - A value that is not finite in SI is E141.
   - `"-0 s"` is stored as 0.0.
   - Where a plain number is expected, anything else is E123.
   - Where a quantity is expected, a number is E123, and `true`, `null`, an array or an object is E141.
4. **Schema pass readings.** Raised by PR #5 and the AKS-87 entry.
   - Quantities and enumerated words are left untyped in the schema, so that they get their own codes.
   - These keys are now required: a parameter's `type`; `run.target` and `run.fidelity` when `run` is present; a scenario's `id` and `set`; `search.objective`.
   - A top-level `ui` is an unknown key.
   - An unknown `domain` gets no domain-specific schema checks.
   - The loader, not the schema, fills defaults for a lower minor version.
   - "`ui` is never read by an engine" can be enforced only from M2.
5. **Loading readings.** Raised by PR #7 and the AKS-88 entry.
   - E123 also covers wrong words, non-whole numbers and wrong shapes.
   - E160 also covers a distribution that cannot be read.
   - `2.0` counts as a whole number.
   - A `quantity` parameter is a time.
   - A missing `seed` is drawn at load from the operating system's generator. An empty `scenarios` list gets `default`.
   - A process constraint takes `<=` and `>=`; an optimization constraint also takes `==`.
   - Setting kinds that spec 2 left open are fixed, and a queue's `discipline` is optional.
   - A missing optimization bound means no bound.
6. **Meaning pass A readings.** Raised by PR #8 and the AKS-89 entry.
   - The identifier pattern and uniqueness also apply to objective, constraint and variable ids and to routes. Scenario ids must be unique within one experiment.
   - `run.engine` selects an adapter by name; it is not checked until adapters exist.
   - The issue sits on a different end or path depending on the code: E130 or E161 by which end is wrong, E131 at the component or the route, E132 at each later `from`.
   - `weights` keys against `routes` are E121 and E122.
7. **Throughput constraints have no rate unit.** A rate constraint takes a plain number of items per second; for example, 30 per hour is written `0.008333`. Raised as an owner question by PR #7 and the AKS-88 entry, and answered provisionally by PR #9 and the AKS-90 entry.
8. **Meaning pass B readings.** Raised by PR #9 and the AKS-90 entry.
   - Setting ranges are E123, not a new code, with the smallest values listed in spec 2 "Ranges".
   - A parameter's `min`, `max` and scenario values are checked against the settings it feeds, jointly at every combination of bounds.
   - E160 also covers a triangular `mode` outside `min` to `max`. A uniform's `min` may equal its `max`.
   - E170 also covers `length`, a negative `warmup`, `record_interval`, `search.budget` and `search.replications`.
   - E171 also covers a search with no variables. A search variable that is not a parameter is E150.
9. **Negative times are not reported.** A time distribution that can give negative times (`constant`, `uniform`, `triangular` or `empirical` below 0 s) gets no issue, because spec 1 lists no such check. Raised by PR #9 and the AKS-90 entry. M2's sampling will meet it.
10. **Warning readings.** Raised by PR #10 and the AKS-91 entry.
    - A server downstream of an overloaded server is checked against the offered rate, not the upstream server's capacity divided by its service time.
    - Only the block a source connects to directly counts as a loss point.
    - W201 and W202 are not checked at a search's `min` and `max`.
    - A source with `max_items` is still checked.
11. **A file whose major version has a migration is still E101 on load,** with a "can convert" hint, rather than being opened in memory. Raised by PR #12 and the AKS-92 entry.

Still open from before M1, not raised by M1: AGPL-3.0-only versus -or-later (M0 entry "Licence file"), and owner questions 2 to 10 of the spec council (2026-11-05).
