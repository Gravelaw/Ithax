## Awaiting owner

No blocking question. These readings are built and in force from 2026-11-15. Each is the default unless the owner changes it:

1. The idle timeout's "never" is the number 0 in `settings.json`, `PUT /v1/settings` and `--idle-minutes`, not `null` or a word (#87).
2. Removing a project takes it off the list and keeps its folder; deleting files is not offered, and removal asks no question (#97).
3. Removal is `POST /v1/projects/{pid}/remove`, not `DELETE`, and it is refused with E188 while a run is queued or running (#97).
4. While a project action is pending, Home disables opening, renaming, removing and starting a lesson and says so (#201).
5. A lesson step or opened time the service refuses is shown in the top bar with "Try again", never taken as saved (#201).
6. `GET /v1/licences` is not an MCP tool (#89).
7. Help hangs off Settings, About, not the navigation rail, which keeps seven screens (#89).
8. Authors are shown as names only; where the metadata names none, the licence's copyright holder is shown (#89).
9. `Capabilities.distribution` (spec 1) names an engine's Python distribution, empty by default (#89).
10. Utilization is called "busy share" on screen (#91).
