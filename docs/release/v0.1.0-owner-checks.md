## 1. Pointer only

1. On a Linux desktop, remove `~/.config/ithax` and `~/.local/share/ithax`, so the app starts fresh.
2. Start Ithax: the AppImage (check 5) or the installed archive (`ithax` from the applications menu).
3. With the mouse only:
   - press Continue on the notice;
   - on Home, press New empty project, give it a name, and create it. A name needs the keyboard, so typing it counts as allowed.
   - from the palette, add a source `arrivals`, a server `till` and a sink `exit`, and connect them in that order;
   - give them the settings of `examples/coffee_shop.json`: arrivals exponential with mean 2 min; the till exponential with mean 1.5 min and capacity 1 (the file names a parameter `tills` with value 1); the experiment 210 h long with 10 h of warm-up and 30 replications;
   - press Run, wait for Done, and open Results.
4. Note each step where the keyboard was needed, other than typing values and the name. C5 keeps the keyboard support already built, and new keyboard work is deferred.
5. Compare the till's mean wait with the template's theory value, 270 s (M/M/1, `templates/coffee_shop/expected.json`): it should be within about three of the standard errors shown.

## 4. Low tier

On the owner's low-tier machine (spec 0 "Platform and hardware"; spec 3 "Hardware tiers"), from a checkout of the tag, or of `main` if before the tag:

```sh
uv sync --locked --extra dev
taskset -c 0-3 .venv/bin/pytest -m perf
```

`taskset` caps the run at 4 cores. Copy each measured figure from the output into `docs/research/performance.md` with the machine's cores, memory and OS. The targets are in spec 3 "Performance targets", spec 2's M3 acceptance row and spec 0 "Success measures". The agent container's figures are already there, marked "not yet on the owner's low-tier machine".

## 5. AppImage

1. Download `ithax-<version>-x86_64.AppImage` and its `.sha256` from the `package` CI job's artifact `ithax-linux-x86_64` on `main`, or from the release page once #103 makes one.
2. Check it: `sha256sum -c ithax-<version>-x86_64.AppImage.sha256` prints "OK".
3. Make it executable, in the file manager's properties or with `chmod +x`, and double-click it.
   - The desktop shell should open Home. It needs WebKitGTK 4.1 (`libwebkit2gtk-4.1-0`), as the archive's shell does.
   - Without WebKitGTK, the interface opens in the browser instead.
4. Start the coffee shop lesson and run its exercise to Results.
5. Close the window. After the idle time (Settings, 30 minutes by default) the service exits, and with it the AppImage's process. `ps` then shows no `ithax` process.
6. Where FUSE is missing, it should still run with `APPIMAGE_EXTRACT_AND_RUN=1 ./ithax-<version>-x86_64.AppImage`.
